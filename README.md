# Resumo do Lab - Computação em Nuvem e Microsoft Azure

Este repositório contém o resumo das lições aprendidas durante a realização dos cursos oferecidos pela DIO sobre Computação em Nuvem e Microsoft Azure.

## Cursos Realizados

1. **Introdução à Computação em Nuvem**  
   - Compreendi os principais conceitos de computação em nuvem, incluindo seus modelos de serviço (IaaS, PaaS, SaaS) e modelos de implantação (pública, privada, híbrida).
   - Entendi os benefícios da nuvem como escalabilidade, disponibilidade, segurança e redução de custos.
   - Aprendi sobre provedores de nuvem e o papel da Microsoft Azure nesse mercado.

2. **Microsoft Azure - Localizando Serviços por Categoria**  
   - Aprendi a navegar pelo portal do Azure e localizar serviços de forma eficiente.
   - Conheci as principais categorias de serviços no Azure, como computação, armazenamento, rede, bancos de dados e inteligência artificial.
   - Entendi como utilizar filtros e ferramentas de busca para explorar os serviços disponíveis na plataforma.

## Conclusão

A experiência com os labs foi essencial para consolidar meus conhecimentos sobre os fundamentos da nuvem e a utilização do Azure como plataforma. Sinto-me mais preparado para explorar soluções baseadas em nuvem no desenvolvimento de sistemas modernos.
